# SPIN CLASH 3D

ブラウザーで遊べる3Dコマバトルです。GitHub Pagesで公開できます。

## ファイル構成

- `index.html` — 画面の部品と読み込むファイル
- `styles.css` — 色、配置、スマートフォン向け表示
- `src/game.js` — 3D表示、物理、CPU、オンライン、カスタム画面
- `audio/` — バトル効果音（必要になったときに読み込みます）

## カスタマイズの場所

`src/game.js` の冒頭にステージ一覧があります。ステージの色や広さ、加速床などを変更できます。その少し下の「Custom parts」からブレード、アーマー、ドライバーを追加できます。部品ごとの名前・色・形・能力値をまとめて編集してください。

見た目の調整は `styles.css`、画面の文言やボタンの配置は `index.html` を編集します。効果音を差し替える場合は `src/game.js` 冒頭の `soundFiles` にあるパスを変更します。新しい音声は `audio/` に置いてください。

## 公開

GitHub Pagesはリポジトリの Settings → Pages で有効にできます。`main` ブランチのルートを公開先にすると、変更を `main` に反映するたびにページが更新されます。
